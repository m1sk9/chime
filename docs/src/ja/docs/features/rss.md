# RSS フィード

`[[rss]]` は syndication フィードを購読し，それまでフィードになかったエントリをすべて投稿します．RSS 0.9x / 1.0 / 2.0，Atom，JSON Feed のすべてに対応しており，形式は本文から判別されるため，`kind` を設定する必要はありません．`url` はフィードそのものであり，書かれたとおりにリクエストされます．chime が何かを付け足すことはありません．これらのいずれでもない本文は，`response is not an RSS, Atom or JSON feed: …` でポーリングに失敗します．これはログに残りますが，致命的ではありません．キーの一覧は [設定](../configuration#rss) にあります．

## 通知のセマンティクス

- **起動後の最初のポーリングは通知しません．** フィードに現在あるエントリをベースラインとして記録します．再起動するとベースラインを取り直します．エントリが 1 つもないポーリングは数えません．ベースラインはエントリのある最初のポーリングで記録されるため，空の状態から始まったフィードの最初のエントリは投稿されません．
- エントリは，その **id** が未確認のときに投稿されます．id は RSS では `<guid>`，Atom では `<id>`，JSON Feed では `id` です．フィードが id を与えない場合は，エントリのリンクとタイトルのハッシュ (リンクがない場合はフィードの URL とタイトル) になります．すでに確認済みのエントリを編集しても再投稿されません．ただし，それ自身の id を持たない場合は別です．その場合，新しいタイトルやリンクは新しい id となり，エントリは再び投稿されます．リンクとタイトルが同じそのようなエントリが 2 つあれば，1 つのエントリとして扱われます．
- id は Discord へのリクエストの**前**に記録されるため，送信に失敗しても再試行されません．
- フィードから消えたエントリは忘れられます．戻ってきた場合は新規として報告されます．エントリがまったくないフィードが返ってきた場合は，ベースラインが保持されます．
- それ自身の id を持たず，リンクもタイトルもないエントリは無視されます．安定して識別できるものがないためです．タイトル，リンク，本文のいずれもないエントリも同様です．
- 1 回のポーリングで複数の新しいエントリがある場合は，エントリ自身の日付で**古い順**に投稿されます．日付のないエントリは，フィードの順序のまま最後に来ます．投稿数に上限はありません．
- ポーリングの失敗 (フィードに到達できない，フィードではない本文) は `warn` でログに残り，投稿されることはありません．

多くのフィード (Claude Code の changelog もその 1 つ) は `cache-control: no-cache` を送り，`ETag` を送りません．そのため検証できず，ポーリングのたびにフィード全体をダウンロードし，Chrome と同様に [サマリー](../how-it-works#knowing-the-poller-is-alive) で `updated` として数えられます．gzip によりそれは小さく収まり，ステータスページと同じ 8 MB の上限が適用されます．

## Discord での表示

新しいエントリは 1 件ごとに 1 つの embed になり，`display_name` の名前で投稿されます．色は固定です (Discord の fuchsia)．

```
2.1.283                                  ← エントリのタイトル．エントリへのリンク
- Added x-claude-code-prompt-id to the gateway hint headers …
- Fixed MCP progress notifications being discarded …
Published: 2026-09-25 22:00 UTC          ← エントリに日付がある場合
code.claude.com · <time chime saw it>
```

本文はエントリの summary，summary がない場合は content で，HTML からプレーンテキストに変換されます．リスト項目は `- ` で始まる行になり，段落と改行は改行になり，`<script>`，`<style>`，コメントは内容ごと除去され，その他のタグは除去されてテキストだけが残ります．フィードがプレーンテキストと指定している Atom と JSON Feed のテキストは，そのまま表示されます．HTML と指定された Atom のタイトルも同じように変換されます．長い本文は切り詰められ，リンク先のページが正本です．タイムスタンプは chime がエントリを検知した時刻であり，エントリ自身の日付ではありません．
